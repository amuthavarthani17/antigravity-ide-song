# 🎵 SoundPulse - Dynamic Music Streaming Platform

A sleek, modern, glassmorphic **Music Streaming Web Application** built with **HTML5, Vanilla CSS, JavaScript (ES6+), and Supabase**. Songs are streamed dynamically using **Cloudinary audio URLs**, complete with a full **Admin Dashboard (CRUD)** for real-time library management.

---

## ✨ Features

### 🎧 User Side
- **100% Dynamic Playback**: No hardcoded songs in DOM. All tracks, album art, and metadata are pulled directly from Supabase.
- **Modern Audio Player**:
  - Play / Pause with glowing equalizer bars
  - Next / Previous track controls
  - Drag-and-drop seekable progress bar with buffered timeline
  - Live duration and current playback timer
  - Volume slider with one-click Mute / Unmute
  - Shuffle and Repeat modes
- **Instant Search**: Search by Song Title, Artist, or Album in real time.
- **View Switcher**: Toggle between responsive Grid View and Compact List View.
- **Rich Dark Aesthetics**: Obsidian glassmorphism (`backdrop-filter`), neon violet and cyan accents, spinning vinyl animation for the active track.
- **Keyboard Shortcuts**:
  - `Space` : Play / Pause
  - `Arrow Left` / `Arrow Right` : Seek backward / forward 5 seconds
  - `Arrow Up` / `Arrow Down` : Volume up / down
  - `M` : Mute / Unmute
  - `S` : Toggle Shuffle
  - `R` : Toggle Repeat

### 🛡️ Admin Dashboard (CRUD)
- **Add Songs**: Form with Song Title, Artist, Album, Cover Image URL, and Cloudinary Audio URL.
- **Live Preview**: Real-time cover art thumbnail preview before saving.
- **Edit Songs**: Edit any existing song; form pre-populates with record data.
- **Delete Songs**: Instant deletion with confirmation dialog.
- **Real-Time Sync**: Instant updates across clients using Supabase subscriptions.

### ⚡ States & Reliability
- **Skeleton Shimmer**: Smooth placeholder animations while tracks load.
- **Empty States**: Friendly guidance when no tracks exist or search yields no matches.
- **Error States & Diagnostics**: Connection test modal to verify Supabase credentials and table health.

## 🗄️ Supabase Table Schema & SQL

Run the following SQL in your **Supabase Dashboard ➔ SQL Editor ➔ New query**:

```sql
-- 1. Create the `songs` table
CREATE TABLE IF NOT EXISTS public.songs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    artist TEXT NOT NULL,
    album TEXT NOT NULL DEFAULT 'Single',
    cover_url TEXT NOT NULL,
    audio_url TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Enable Row Level Security (RLS)
ALTER TABLE public.songs ENABLE ROW LEVEL SECURITY;

-- 3. Create RLS Policies
-- Allow anyone to view songs
CREATE POLICY "Public songs are viewable by everyone" 
ON public.songs FOR SELECT USING (true);

-- Allow anyone to add songs (for this demo/dashboard)
CREATE POLICY "Anyone can insert songs" 
ON public.songs FOR INSERT WITH CHECK (true);

-- Allow anyone to update songs
CREATE POLICY "Anyone can update songs" 
ON public.songs FOR UPDATE USING (true) WITH CHECK (true);

-- Allow anyone to delete songs
CREATE POLICY "Anyone can delete songs" 
ON public.songs FOR DELETE USING (true);

-- 4. Enable Supabase Realtime for instant updates
BEGIN;
  DROP PUBLICATION IF EXISTS supabase_realtime;
  CREATE PUBLICATION supabase_realtime FOR TABLE public.songs;
COMMIT;

-- 5. Seed initial sample song with the provided Cloudinary URL
INSERT INTO public.songs (title, artist, album, cover_url, audio_url)
VALUES (
    'Ey Inga Paaru', 
    'StarMusiQ Artists', 
    'Kollywood Beats', 
    'https://images.unsplash.com/photo-1511671782779-c97d3d27a1d4?auto=format&fit=crop&w=800&q=80', 
    'https://res.cloudinary.com/tyqpilxi/video/upload/v1790314415/Ey_Inga_Paaru-StarMusiQ.Com.mp3'
);
```

## 🚀 Supabase Setup & Configuration Steps

1. **Create a Supabase Project**:
   - Go to [Supabase](https://supabase.com/) and sign in.
   - Click **New Project** and name it (e.g. `soundpulse-music`).
2. **Execute the SQL Script**:
   - Go to **SQL Editor** on the left menu.
   - Paste the SQL script above (or from [`supabase_setup.sql`](file:///c:/Users/mahas/Desktop/antigravity%20ide%20song/supabase_setup.sql)) and click **Run**.
3. **Copy API Keys**:
   - Go to **Project Settings** (gear icon) ➔ **API**.
   - Copy the **Project URL** (`https://<project-ref>.supabase.co`).
   - Copy the **anon public API key** (`eyJhbGci...`).
4. **Connect the App**:
   - **Method A (In-Browser)**: Open `index.html`, click the ⚙️ **Settings** icon in the top header, paste your URL and Key, then click **Test Connection** & **Save & Connect**.
   - **Method B (Config File)**: Open [`config.js`](file:///c:/Users/mahas/Desktop/antigravity%20ide%20song/config.js) and paste your credentials directly into `supabaseUrl` and `supabaseKey`.

## ☁️ Cloudinary Audio Streaming

Cloudinary provides high-performance global CDN delivery for audio files. When uploading songs to Cloudinary:
- Upload under **Video / Audio**.
- Ensure the resource is public.
- Copy the direct MP3 link (e.g., `https://res.cloudinary.com/<cloud-name>/video/upload/v.../<song-name>.mp3`).
- In the Admin Dashboard, paste this into the **Cloudinary Audio URL** field.

Example audio URL included:
```
https://res.cloudinary.com/tyqpilxi/video/upload/v1790314415/Ey_Inga_Paaru-StarMusiQ.Com.mp3
```

## 🖥️ Running Locally

Because this application uses standard static files, you can run it in multiple ways:

### Option 1: Direct in Browser
Simply open [`index.html`](file:///c:/Users/mahas/Desktop/antigravity%20ide%20song/index.html) in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
Using Node.js:
```bash
npx -y serve .
```
Or using Python:
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000`.
